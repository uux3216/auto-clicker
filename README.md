# SPI Flash Programmer (CH341A/B) — Android স্টার্টার

## ফিচার
- চিপ শনাক্ত (JEDEC ID, নির্মাতা, পার্ট, সাইজ, Status Register)
- পুরো চিপ রিড + Hex ভিউ (অফসেটে "যাও" সহ) + `.bin` সেভ
- চিপ ইরেজ + ব্ল্যাঙ্ক ভেরিফাই
- ফাইল থেকে রাইট + ভেরিফাই (আলাদা ভেরিফাই বাটনও আছে)

## বিল্ড (পিসি ছাড়া — GitHub Actions)
1. GitHub-এ নতুন রিপোজিটরি বানিয়ে এই প্রজেক্টের সব ফাইল (`.github` ফোল্ডারসহ) পুশ করুন
2. রিপোর **Actions** ট্যাবে "Build APK" চলবে (না চললে Run workflow চাপুন)
3. রান শেষ হলে নিচে **Artifacts** থেকে `spiflash-debug-apk` নামিয়ে জিপ খুলুন
4. `app-debug.apk` ইনস্টল করুন (অজানা উৎস থেকে ইনস্টলের অনুমতি লাগবে)
5. USB OTG সাপোর্টেড ফোনে প্রোগ্রামার প্লাগ করলে অ্যাপ খুলবে ও পারমিশন চাইবে

কম্পাইল এরর হলে Actions রানের লগ দেখুন।

## সতর্কতা
- **ভোল্টেজ:** অনেক কালো CH341A বোর্ডে ডেটা লাইনে 5V আসে। 3.3V চিপে 3.3V মোড করা বোর্ড বা লেভেল-শিফটার ব্যবহার করুন; 1.8V চিপে 1.8V অ্যাডাপ্টার।
- **অপরীক্ষিত কোড:** এটি হার্ডওয়্যারে টেস্ট করা হয়নি। প্রথমে একটি পুরনো/অপ্রয়োজনীয় চিপে চালান। ইরেজ/রাইটের আগে রিড করে ব্যাকআপ রাখুন।
- **স্পিড:** `Ch341Driver.BATCH_PACKETS` (এখন 16) বাড়ালে দ্রুত হয়, তবে USB stall হলে কমিয়ে দিন।

## সীমাবদ্ধতা
- শুধু স্ট্যান্ডার্ড SPI NOR (0x9F/0x03/0x06/0x02/0xC7)। EEPROM (25xx), NAND, I2C সাপোর্ট নেই।
- ১৬MB-এর বেশি চিপে 4-byte কমান্ড (0x13/0x12) ব্যবহার হয় — টেস্ট হয়নি।
- Write-protect (BP বিট) সরানোর ফিচার নেই; প্রোটেক্টেড চিপে ইরেজ/রাইট ভেরিফাইতে ধরা পড়বে।
- `ChipDb.kt` এর ডাটাবেস ছোট। অজানা সাইজের চিপে সাইজ হাতে বাছতে হয়।
- ডাটা RAM-এ রাখা হয় (`largeHeap` চালু)।
